# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short: be kind, assume good intent, keep criticism about the work and not the person, and make it easy for newcomers to take part.

To report unacceptable behaviour, contact the maintainer privately through a [GitHub security advisory](../../security/advisories/new) or the email on the maintainer's GitHub profile. Reports are handled confidentially.
