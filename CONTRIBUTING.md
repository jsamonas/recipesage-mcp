# Contributing

Thanks for helping. This is a small project and a friendly place for first-time contributors.

## Ways to help
- **Report a bug or suggest a feature:** open an issue using the templates.
- **Improve the docs:** typo fixes count.
- **Write code:** comment on an issue first, so two people don't build the same thing.

## Making a change
1. Fork the repo and create a branch from `main` (for example `feature/search-recipes`).
2. Keep each pull request to one change, and describe what it does and how you tested it.
3. Never commit credentials, session tokens or `.env` files.
4. Open the pull request. A maintainer will review it, usually within a few days.

## Style
- Small, readable functions, with comments where the RecipeSage API behaves unexpectedly.
- Plain-language README and error messages. Users may not be developers.

## AI-assisted contributions
This project is built with help from AI coding assistants, and that's fine for contributors too. You're responsible for understanding and testing whatever you submit.
